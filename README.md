# obsidian-starter-template

## What is this?

This is my Personal Knowledge Management (PKM) starter template for [Obsidian](https://obsidian.md/). It draws inspiration from frameworks like [Getting Things Done](https://gettingthingsdone.com/what-is-gtd/), [Building a Second Brain](https://fortelabs.com/blog/basboverview/), [Linking Your Thinking](https://youtu.be/lqrzxfZD_hc?si=rxW5L0VzBrfhRXQV) and [Zettelkasten](https://www.amazon.co.uk/How-Take-Smart-Notes-Technique-ebook/dp/B09V5M8FR5/) - adapted to how I process and organise information. 
## Why do I need it?

This template is customised to my preferences, so it may not be a good fit for you. However, you might find useful ideas for structuring your own PKM system in Obsidian.
## OK, how do I get started?

Clone repo, open the repo folder as a vault in Obsidian, update plugins. 
## What else?

This template is a permanent work in progress — I update it as my system evolves.
